The rulebook team did not submit paid generations or test account-level access. Vendor demonstrations describe potential results. Reproducible shot-level reliability remains an empirical question.

## Mode distinctions

- **New shot or scene material.** Text or image/video/audio references generate new output. The duration of an input reference is separate from requested output duration. Consult the [profile registry](../ai_production/seedance_profiles.yaml) and the live documentation for all file-size, aspect, rate and account limits.
- **Start and end frame control.** The Ark first/last roles and the omni-reference path differ. The provider describes dedicated roles as stronger endpoint controls with an aspect-ratio consequence. In the omni path, prompt-based endpoint references guide the output without the same frame-match behavior. Inspect both endpoints and the motion between them. [2.5 prompt guide](../sources/bibliography.md#src-volc-p25)
- **Editing.** Give a source video and the change scope. The duration can inherit from the source. Use timestamp-directed edits as a vendor-described capability where supported, and inspect whether neighboring frames or audio changed. [Ark API](../sources/bibliography.md#src-volc-gen) · [fal schema](../sources/bibliography.md#src-fal-25r)
- **Extension.** Specify whether to continue before or after the source, the desired added action and a join point. Record whether the output contains only the new segment or overlaps or includes the original. Compare the seam, phase, identity, geography and audio. A multi-round timeline duration describes a different operation from a single generation. [2.0 tutorial](../sources/bibliography.md#src-volc-20) · [2.5 model page](../sources/bibliography.md#src-morph-25)
- **Camera and audio.** Providers describe prompt- and reference-based camera control and generated dialogue, music, effects or ambience. No source establishes exact pose trajectories, frame-accurate timing, deterministic lip sync or cross-clip identity. Test the current mode, speaker, language and shot conditions. [2.0 launch](../sources/bibliography.md#src-seed-20) · [2.5 release](../sources/bibliography.md#src-seed-25) · [Morphic guide](../sources/bibliography.md#src-morph-20)

## Timing evidence and a reproducible check

The 2.5 release and prompt guide describe timestamp-level **editing**. Morphic treats timecodes in a generation prompt as hints. These sources support using an ordered motion brief and checking the output. They supply no calibrated timing accuracy for fresh shot generation. [2.5 release](../sources/bibliography.md#src-seed-25) · [2.5 prompt guide](../sources/bibliography.md#src-volc-p25) · [Morphic 2.0 guide](../sources/bibliography.md#src-morph-20)

To verify a particular account and mode, keep the frames, model, duration, aspect ratio and reference roles fixed. Compare otherwise identical ordered and timestamped briefs for a simple camera cue and a visible subject action. Predefine timing tolerance, such as half a second for an exploratory comparison, and check several independent outputs per condition. Record onset error, ordering, endpoint match, continuity and unusable takes. Use the editor for a frame-specific sync or cut. Preserve the tested date, settings and footage ID in the project log.

## Production implication

Start with a 15-second planning ceiling and use the supported minimum when a shot needs less raw material. A five-minute short with an illustrative mean of five **retained** seconds per shot has about 60 edited shots. That estimate comes from the edit, and excludes any separately budgeted credits. Generation count can rise with handles, coverage and retakes, or fall if one generated clip yields several edited shots. Story scene lengths remain independent of this arithmetic.
