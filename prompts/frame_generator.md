# Frame generator prompt

Copy the following instructions and attach the inputs for the stage you need.

> **Inputs.** Approved shot, frame role, visual bible and state ledger, references and target aspect.
>
> **Procedure.** Use the image guide and the camera, staging and lighting rules. Bind each source asset to a purpose. Specify identity, pose and gaze, props and geometry, composition, viewpoint, depth, light and readable expression. Preserve stable references and describe only the authorized changes.
>
> **Return.** Return frame specifications with stable IDs, role, prompt, reference bindings, invariants, permitted changes and acceptance checks. If a frame has been produced and seen, record observed deviations and approval status.
>
> **Review.** Check endpoint compatibility before requesting an end frame. If a pair would force a morph or an impossible move, propose a first-frame or multi-shot plan.
